Validation boundaries

P

Pencil design/export validation

检查设计方向、信息层级和导出图；不声明真实网页渲染已经通过。

B

Browser MCP screenshot validation

打开真实 HTML，检查桌面和移动截图、DOM 快照和 console errors。

S

Script dry-run validation

通过 check-all、skills dry-run 和 MCP dry-run 确认配置链路仍闭环。
