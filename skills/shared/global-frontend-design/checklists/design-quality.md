# 设计质量检查清单

新界面、重设计、视觉打磨和 UI review 时使用。本清单用于核对 [../references/design-principles.md](../references/design-principles.md)，不是新的流程来源。

## 视觉方向

- [ ] UI 有明确命名的视觉方向。
- [ ] 方向符合产品目标和受众。
- [ ] 设计不是泛化 AI / SaaS 模板。
- [ ] 至少有一个产品特定的记忆点。

## 主题可见性

- [ ] 字体选择或字号阶梯有意图。
- [ ] 色彩有清楚角色，并服务主题。
- [ ] 空间、密度和分组形成稳定节奏。
- [ ] 构图不是平均用力。
- [ ] 边框、阴影、渐变、纹理或扁平化选择服务视觉主题。
- [ ] 动效有目的且不过量。

## 层级和可用性

- [ ] 主操作明显。
- [ ] 次操作视觉权重更低。
- [ ] 危险操作被清晰区分且足够谨慎。
- [ ] 元信息处于次要视觉层级。
- [ ] 空状态、错误和帮助文案清楚。
- [ ] 长内容不会破坏布局。
