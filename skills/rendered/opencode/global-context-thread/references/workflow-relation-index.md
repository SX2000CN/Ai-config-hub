# 工作流关系索引

非代码复杂任务可以用任务卡中的 `关系索引` 保存接手所需的结构关系。它不是日志，也不是完整项目管理表。

## 触发条件

只在满足下列至少一项时使用：

- 任务跨会话、跨工具或多人 / 多 AI 接手。
- 存在多个对象、状态、依赖、验证证据或外部约束。
- 后续 AI 如果只读普通上下文，容易误判先后顺序或影响范围。

## 推荐格式

```markdown
## 关系索引

| 对象 | 当前状态 | 依赖 / 影响 | 证据 | 下一步 |
|---|---|---|---|---|
| `<对象或文件>` | <已完成 / 待确认 / 阻塞 / 推断> | <依赖谁或影响谁> | `<文件>` / <命令结果> | <最小动作> |
```

## 内容边界

- 一行只写一个对象或关系，不写长段故事。
- 证据优先写文件、命令或用户确认来源。
- 推断必须标明是推断。
- 没有接手价值时不要创建这个区块。
