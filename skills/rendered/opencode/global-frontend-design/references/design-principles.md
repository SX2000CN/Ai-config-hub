# 视觉方向与审美原则

创建、重设计、明显打磨或 review 前端界面时，优先使用本参考。本文件是视觉判断主源；营销防模板细则见 [anti-slop.md](anti-slop.md)，产品落地见 [product-ui-engineering.md](product-ui-engineering.md)。

## 先有观点，再有组件

强 UI 需要明确立场。不要先问「组件怎么摆」，先回答：

- 这个界面应该给人什么感觉？
- 用户第一眼应注意到什么？
- 哪个选择让它属于**这个**产品/题材，而不是任意模板？
- 哪个细节会被记住，同时不损害可用性？

答不出就写短 brief，不要直接堆代码。

## 扎根题材（subject-grounded）

辨识度来自题材世界，不是来自「酷」的通用特效。

1. 先命名**具体题材**、受众、这一屏的单一工作。
2. 从题材的材料、器物、工具、场景、行话里取视觉隐喻（字体、色、构图、材质）。
3. 用真实内容与真实数据结构填充，避免 Acme / Jane Doe / 假指标装饰。
4. 结构装置（编号、eyebrow、分割线、标签）必须编码真实信息；内容不是序列就不要硬上 `01 / 02 / 03`。

Hero（尤其营销）应是 **thesis**：题材世界里最有特征的一击——标题、真图、真交互 demo、关键数据时刻——而不是「大数字 + 小标签 + 渐变点缀」的默认答卷。

## 一个美学风险（one signature）

在整页/整屏上只押注**一处**可辩护的大胆选择：

- signature 必须能用一句话说清「为什么是这个题材」
- 周围保持纪律：同一主题、同一圆角体系、同一强调色
- 不为「显得有设计」叠加第二、第三套装饰语言
- 最小方向同样需要精度：留白、字阶、对齐，而不是空

未承担任何风险、又没有任何产品特定记忆点的「干净」，通常仍是模板。

## 选择并命名视觉主题

给方向起名，并保持单一主题。示例族（选用，勿混搭过多）：

- 极简、快速、克制
- 编辑部 / 内容驱动
- 高密度企业指挥中心
- 柔和消费级 SaaS
- 工业工具感
- 轻快引导 / 触感创作
- 精致高级、低噪音
- 几何 / 装饰艺术（慎用，易假）
- 自然有机（须来自题材，勿默认米色黄铜）

## 字体承载性格

- 展示与正文**有意**配对，建立字阶与字重节奏；数字与表格考虑等宽或 tabular nums。
- 不要每个项目都默认同一套「安全 sans」；也不要每个创意 brief 都默认衬线。
- **衬线**仅在品牌点名、或题材确实是编辑/出版/奢侈/heritage 且说得出理由时使用；「感觉更高级」不是理由。
- 标题内强调：优先同族 italic/bold，避免为了花样在一句里硬塞第二种族。
- 营销展示字若用 italic，注意 descender（y g j p q）行高与裁切。

## 颜色与表面

- 主表面 + **最多一个**主强调色；语义色（成功/警告/危险）与品牌强调分工清楚。
- 中性色冷暖统一，不要一页里灰系乱跳。
- 阴影色调贴近背景，避免纯黑脏影。
- 卡片只在 elevation 真的表达层级时使用；否则用分割、分组、留白。
- 圆角体系全局锁定（全直角 / 统一软角 / 交互 pill 规则写清并遵守）。

## 构图是信息

- 层级用尺寸、字重、对比、位置、分组表达，而不是到处加框。
- 高 variance：有意识的非对称、分栏、叠置；低 variance：稳网格与对齐纪律。
- 高 density：一致的座舱节奏，禁止为了「现代」乱加卡片外套。
- 营销页避免连续多段同构（反复「左图右文」之字形超过两段应打断）。

## 动效有动机

- 一个编排好的时刻通常强过四处微动。
- 每条动画能用一句话说明：层级 / 叙事 / 反馈 / 状态过渡。
- `MOTION` 声明较高时，页面上要有真实动效，而非只写在方案里。
- 尊重 `prefers-reduced-motion`；动效不得阻挡任务完成。

## 文案是设计材料

- 用用户能控制、能识别的词，不用系统内部名。
- 按钮：具体动作（「保存更改」优于「提交」）；全流程同一意图同一措辞。
- 空状态与错误：说明原因与下一步；错误不卖萌、不模糊。
- 营销文案具体优于俏皮；避免空洞形容词堆砌。

## 避免泛化 AI UI

除非 brief 明确要求，避免：

- 白底紫蓝渐变 + 圆角卡片模板脸
- 无产品理由的居中 hero + 三等分功能卡 + 通用 CTA
- 随机 blob、廉价光晕、无意义全站玻璃拟态
- 所有区块同等用力的平均布局
- 默认字族 + 默认圆角 + 默认阴影堆出的「差不多」
- 为了「高级」牺牲对比度、可读性或操作确定性
- 当前模型扎堆的三种「看起来很设计」默认脸：暖米衬线赤陶、近黑单点酸绿/朱红、broadsheet 细线零圆角——**只有 brief 真需要时才用**，否则当轴自由时不要把自由度花在这些默认上

安全、干净、可用 ≠ 平庸。克制也必须是选择。

## 设计成功标准

完成设计或 review 前检查：

- [ ] 有 Design Read（类型 / 受众 / 语气 / 轨道）
- [ ] 有命名视觉方向，且扎根题材
- [ ] 有且仅有一个清晰 signature（或明确选择「精度型最小」并执行到位）
- [ ] 三旋钮与轨道匹配
- [ ] 主题能在字 / 色 / 空间 / 构图 / 表面 / 动效中看见
- [ ] 主操作、次操作、危险与元信息层级清楚
- [ ] 不是无产品理由的通用 AI / SaaS 模板
- [ ] 产品轨道：状态与可操作完整；营销轨道：首屏 thesis 与节奏成立
