# Anti-slop（营销与高辨识度界面）

在 **marketing** 轨道、品牌页、落地页、作品集、或用户明确要求「不要 AI 味 / 要有设计感」时加载。
**产品轨道不要整份照搬**：仪表盘与密集表单以 [product-ui-engineering.md](product-ui-engineering.md) 为准；此处仅在产品壳需要品牌感时点状借鉴。

本文件吸收公开审美 skill 的方法（Design Read、防默认、一致性锁、出货闸门），用本仓库语言重写；**不是**任何上游全文再发布，也不强制其技术栈（React/Next/GSAP/特定图标库等）。

## 1. 先读 brief，再碰默认

见 workflow 的 Design Read。额外强调：

- 受众选美学，不是模型偏好选美学。
- 已有 logo/色/字/摄影是 redesign 的材料，不是可忽略附件。
- 一次只问一个分叉问题（例如 Linear-clean vs 实验向）；能推断则不问。

## 2. 默认脸黑名单（无 brief 授权时禁止当起点）

- AI 紫 / 蓝光晕按钮与紫粉渐变网
- 暗底 mesh + 居中 hero + 三等分功能卡 + 通用 CTA
- 全站玻璃拟态、随机 blob
- Inter（或同一「安全 sans」）+ slate-900 无思考默认
- 暖米/奶油底 + 黄铜/赤陶/espresso 的「精品消费默认盘」（除非题材与品牌明确要求）
- 每节必上的 uppercase tracking eyebrow、装饰性 `01 / 02` 编号
- 假截图 div、假头像墙、「Quietly used by」空话
- 一页内多套强调色、多套圆角、中段突然反色主题（无理由）

## 3. 一致性锁（Consistency Locks）

出货前机械检查：

| 锁 | 规则 |
|---|---|
| **主题** | 全页一种主主题（浅 / 深 / 系统）；禁止无叙事理由的区块级乱翻面 |
| **强调色** | 一个主 accent 贯穿；勿第 7 节突然换品牌色 |
| **圆角** | 一种 radius 体系；若按钮 pill、卡片 12px，写清规则并全局遵守 |
| **CTA 意图** | 同一意图一种措辞（「联系我们」与「聊一聊」勿并存） |
| **图标族** | 跟随项目已有；不混多套描边语言；不手绘一堆无源 SVG 图标充数 |

## 4. 布局纪律（营销页）

- **Hero 是单一时刻**：eyebrow/品牌条（0–1）+ 标题（桌面 ≤2 行）+ 副文（宜短）+ CTA（1 主 + 可选 1 次）。信任 logo 墙、定价条、功能列表放到 hero **下方**独立区块。
- **首屏**：主 CTA 应在首屏可见；标题字号与主视觉**一起**规划，勿标题爆到四行。
- **导航**：桌面单行；高度克制，勿吞掉首屏。
- **区块家族**：同页少重复同一种 section 骨架；「左图右文」之字连续 ≤2，第 3 段必须换家族。
- **Eyebrow 配额**：约每 3 个 section ≤1 个微标签；多数标题不需要 uppercase 小字。
- **Split-header 默认禁**：不要「左大标题 + 右栏解释段」当默认 section 头；需要解释则纵向叠在标题下（max ~65ch）。
- **Bento**：有 N 块内容就 N 格；禁止空占位格；至少部分格子有真实视觉变化（图/质感），勿六张同构白卡。
- **居中 hero**：VARIANCE 较高时优先分屏/非对称；宣言页可居中。

## 5. 字体与调色（防 AI tell）

- 展示字有性格，但**同项目可复现**；勿每个项目换一套「网上流行展示衬线」。
- 衬线默认克制：见 design-principles；Fraunces / Instrument Serif 等「模型爱用展示衬线」无品牌理由时不要当默认。
- 精品消费向：主动轮换冷奢银灰、森林、单色+一点高饱和等，避免永远米色黄铜。
- 按钮与表单对比：WCAG AA 心智（正文约 4.5:1，大字约 3:1）；白字白底、幽灵按钮贴摄影无 scrim → 失败。
- CTA 文案桌面不换行；过长就改文案或加宽，勿压扁按钮。

## 6. 动效与材质

- 动效必须有动机；编排一个时刻优于四处 `animate`。
- 尊重 reduced motion。
- 卡片阴影色调跟背景；高 DENSITY 时少用通用大卡片套壳。
- 不引入新动画库，除非用户要求或项目已有。

## 7. 文案 anti-slop

- 禁用空洞企业黑话与假社交证明。
- 引语保持短、可归因；勿为版式编造评价。
- 版本号、`BETA` 角标、天气/城市装饰条、Scroll 提示箭头：无 brief 需要则不要。
- 图片上勿叠无意义的 `Plate · Brand` 式标签装饰。

## 8. 工程边界（与 hub 一致）

- **不**因本文件改用指定框架或强制安装 GSAP / 某图标包 / 某设计系统。
- 若 brief 明确对应企业设计系统（Fluent、Carbon、Polaris、GOV.UK 等）：**优先项目已有**；未安装则询问，不擅自加依赖。
- 实现仍走 workflow：复用、最小 diff、验证、密钥不进库。

## 9. 营销出货闸门（浓缩）

完整勾选见 [../checklists/preflight-marketing.md](../checklists/preflight-marketing.md)。心检：

1. Design Read + 旋钮 + signature 已声明且与页面一致
2. 三把一致性锁通过
3. Hero 纪律与 eyebrow 配额通过
4. 无默认脸黑名单项
5. 动效有动机且 reduced motion 有路径
6. 真内容、真对比度、可点击主路径
