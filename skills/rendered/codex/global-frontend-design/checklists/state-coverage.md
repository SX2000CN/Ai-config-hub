# 状态覆盖检查清单

宣称 UI 达到生产级前使用。详细原则见 [../references/responsive-state-coverage.md](../references/responsive-state-coverage.md)。

## 数据状态

- [ ] 初始加载状态清楚且布局稳定。
- [ ] 有空状态。
- [ ] 存在筛选 / 搜索时，有筛选后空状态。
- [ ] 有错误状态。
- [ ] 可行时提供重试或恢复路径。
- [ ] 部分数据不会破坏布局。

## 交互状态

- [ ] hover、focus、active / selected 状态清楚。
- [ ] disabled / unavailable 状态清楚，并在必要时说明原因。
- [ ] 保存 / 提交中能按需防止重复操作。
- [ ] 需要时有成功确认。
- [ ] 校验失败可见且可操作。

## 内容极端情况

- [ ] 长名称会有意识地换行、截断或 clamp。
- [ ] 大数字和计数能放得下。
- [ ] 很多项目时仍可用。
- [ ] 0 个项目时仍有用。
- [ ] 权限受限状态可理解。
