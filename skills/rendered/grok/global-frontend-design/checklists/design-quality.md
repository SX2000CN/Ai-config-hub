# 设计质量检查清单

新界面、重设计、视觉打磨和 UI review 时使用。核对 [../references/design-principles.md](../references/design-principles.md)，不是新的流程来源。

## Design Read 与方向

- [ ] 有明确 Design Read（类型 / 受众 / 语气 / 轨道）
- [ ] UI 有命名视觉方向，且扎根题材
- [ ] 轨道（product / marketing / hybrid）选择合理
- [ ] 三旋钮已设定并与轨道匹配
- [ ] 有一个可辩护 signature，或明确的精度型最小并执行到位
- [ ] 不是泛化 AI / SaaS 模板脸

## 主题可见性

- [ ] 字体选择或字阶有意图
- [ ] 色彩角色清楚；主强调色一致
- [ ] 空间、密度和分组形成稳定节奏
- [ ] 构图不是平均用力
- [ ] 边框、阴影、纹理或扁平化服务主题
- [ ] 圆角 / 主题 / 强调色锁一致
- [ ] 动效有目的且不过量；高 MOTION 时真实可见

## 层级和可用性

- [ ] 主操作明显
- [ ] 次操作视觉权重更低
- [ ] 危险操作被清晰区分
- [ ] 元信息处于次要层级
- [ ] 空状态、错误和帮助文案清楚（product）
- [ ] 长内容不会破坏布局
- [ ] 营销页：Hero thesis 与区块节奏成立（若适用）
