# 营销页 Preflight

**marketing** 轨道 full 交付前使用。product-only 界面不要整表硬套。细节见 [../references/anti-slop.md](../references/anti-slop.md)。

## 声明

- [ ] Design Read 一行已成立
- [ ] 旋钮有 brief 理由，非无思考套默认
- [ ] 命名方向 + 一个 signature
- [ ] 未擅自新增依赖 / 平行设计系统

## 一致性锁

- [ ] 全页主题一致（无乱翻面）
- [ ] 单一主强调色贯穿
- [ ] 圆角体系一致
- [ ] 同一 CTA 意图同一措辞
- [ ] 图标族与描边语言一致

## 布局与 Hero

- [ ] Hero 元素克制（标题 / 短副文 / CTA）；信任墙不在 hero 内抢戏
- [ ] 首屏可见主 CTA；标题未失控折行
- [ ] 桌面导航单行、高度克制
- [ ] 无 3+ 连续同构「图文之字」section
- [ ] Eyebrow 未滥标（约每 3 section ≤1）
- [ ] 无默认 split-header 废话栏
- [ ] Bento/网格：内容格数正确，非空壳重复卡

## Anti-slop

- [ ] 无紫蓝光晕 / 三等分万能卡 / 无意义玻璃与 blob 当默认
- [ ] 无无理由的模型默认「三种设计脸」
- [ ] 无假品牌、假证言、装饰性版本号与 scroll 提示
- [ ] 按钮与表单对比度可接受；CTA 桌面不折行
- [ ] 动效可一句说明动机；reduced motion 有路径

## 验证

- [ ] 目标路由可渲染；关键断点扫过
- [ ] 控制台无本次错误
- [ ] 方向与 signature 在屏幕上可见
