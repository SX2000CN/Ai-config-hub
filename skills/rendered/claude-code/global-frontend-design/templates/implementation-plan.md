## 实施步骤

1. 检查目标文件和已有组件。
2. 若任务是设计请求，先确认 UI brief 或现有设计证据，再按视觉方向更新结构和内容。
3. 按项目原生模式应用样式。
4. 补齐或更新状态覆盖。
5. 用命令和浏览器检查验证。
6. 若影响行为、配置、流程或长期项目理解，同步更新文档。
