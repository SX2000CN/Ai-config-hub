# Review 检查清单

最终 UI review 或前端 diff review 时使用。

## 范围

- [ ] 改动匹配用户请求的界面。
- [ ] 没有无关重设计或重构。
- [ ] 遵守项目已有约定。
- [ ] 未经确认不新增依赖。

## 视觉方向

- [ ] 有明确命名的视觉方向。
- [ ] 方向符合产品语境。
- [ ] 不是泛化 AI / SaaS 模板感。
- [ ] 至少有一个产品特定记忆点。

## 层级和构图

- [ ] 主操作、次操作和危险操作层级清楚。
- [ ] 信息易扫读。
- [ ] 间距节奏一致。
- [ ] 字体、颜色、表面和动效服务产品目标。

## 生产就绪度

- [ ] 状态覆盖足够。
- [ ] 可访问性没有倒退。
- [ ] 响应式行为已检查。
- [ ] 考虑了真实数据极端情况。
- [ ] 能做浏览器验证时，已检查控制台错误。

## 交接

- [ ] 已报告视觉方向和关键视觉动作。
- [ ] 已报告验证命令。
- [ ] 已报告浏览器/手动检查。
- [ ] 已处理文档影响。
- [ ] 已说明残留风险。
