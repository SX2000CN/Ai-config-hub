# 响应式检查清单

页面级和布局级 UI 修改使用。详细原则见 [../references/responsive-state-coverage.md](../references/responsive-state-coverage.md)。

## 布局模式

- [ ] 移动端布局是有意设计的，不是被挤压的桌面端。
- [ ] 如相关，平板或中等宽度布局可接受。
- [ ] 桌面端布局是有意设计的。
- [ ] 宽屏桌面不会把内容拉得过散。

## 组件

- [ ] 导航能合理适配。
- [ ] 表格 / 列表仍可用。
- [ ] 表单仍易读且易提交。
- [ ] 弹窗能适应小屏，或改成 sheet / 全屏面板。
- [ ] 图表、媒体和卡片调整尺寸后不重叠。

## 内容和操作

- [ ] 文本换行后不重叠。
- [ ] 按钮仍可到达。
- [ ] sticky 或 fixed 元素不会遮挡重要内容。
- [ ] 触控目标可用。
- [ ] 横向滚动是有意设计的，而不是意外溢出。
