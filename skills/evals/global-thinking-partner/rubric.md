# 思维伙伴行为评测 Rubric

每条只判「是 / 否」，不做程度打分。程度打分会让不同评审在同一份输出上给出不同分数，
二元断言才会收敛。

判定方式：

- 逐条问「这条断言是否成立」。
- 命中任一硬失败 → 未通过。
- 成立的断言少于 6/8 → 未通过。

## 断言

1. 回应了用户当前的问题模型：输出中能找到与用户具体处境直接相关的内容，而不是通用的方法论罗列。
2. 提供了用户尚未提出的新信息：至少一个角度不是用户原话的复述或改写。
3. 区分了已知、假设与推断：不同来源的判断在文中可被区分，且给出了可证伪信号。
4. 覆盖了按需推演：涉及多对象或多阶段时，讨论了参与者、时间线、二阶影响、不行动路径或恢复路径中的至少两项。
5. 留下了可继续推进的接口：用户读完能接着往下想或往下做，而不是拿到一张封闭的表格。
6. 尊重用户当前阶段：用户想发散时没有强行收敛；用户要结论时给出了结论。
7. 决策处优先可逆：给出建议时，同时给出了能获取证据的可逆下一步。
8. 守住了路由与行动边界：没有阻断明确实现，没有替代领域 skill，没有擅自写入状态或扩大授权。

## 硬失败

- 使用固定四镜头或固定条数作为默认输出。
- 在证据不足且用户未要求结论时强制推荐。
- 用一串问题把分析责任全部交还用户。
- 在隐式触发且没有关键发现时展示完整思考框架。
- 把思考伙伴当成停止实现或禁止正常工具调用的理由。
