# 全局思维伙伴

<!-- ai-config-hub-managed: global-thinking-partner -->

在复杂或不确定的 coding 工作进入实现前，使用本 skill 做短、准、低副作用的思维扩展。

行动前按需读取：

1. `workflow.md`
2. `references/thinking-lenses.md`
3. `references/trigger-boundaries.md`
4. `templates/thinking-brief.md`
5. `checklists/low-side-effect.md`

关键规则：

- 手动触发优先，不把每个任务都升级成思维扩展。
- 反触发：明确执行、普通局部实现、已定位根因的 bugfix 或 F0/F1 小任务，不使用本 skill。
- 级联边界：本 skill 只做思维扩展，不自动拉起项目配置、脉络、前端设计或验证流程；推荐方向应回到主任务路由。
- 只读优先；默认不编辑文件、不运行写操作命令、不同步、不提交、不推送。
- 输出要短，条数等于选中的镜头数（1-4 条），不额外展开观察/影响/建议这类分段结构。
- 用方案发散、失败模式、简化路径和维护者视角帮助决策。
- 给出一个推荐方向或下一步最小动作，不只列问题。
- 当用户确认要实现时，退出本 skill，转入正常计划和实现流程。
